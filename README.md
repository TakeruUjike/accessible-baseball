# ユニバーサル・ベースボール (Universal Baseball)

**ユニバーサル・ベースボール**は、全盲や視覚障害を持つプレイヤーをはじめ、誰もが完全に同じ条件で楽しめるように設計された、Webベースの音声読み上げ完全対応の野球ゲームです。

バックエンドはGo言語で記述され、フロントエンド（HTML/CSS/JS）の静的ファイルをすべて埋め込んだシングルバイナリとして動作するため、複雑なインストール作業なしに手軽に遊ぶことができます。

---

## 🌟 特徴

- **スクリーンリーダー完全対応**: すべてのゲーム画面、投球情報、打撃結果、現在のカウント（SBO）やスコアが、スクリーンリーダー（NVDA、PC-Talker、ナレーター等）でスムーズに読み上げられます。
- **直感的なキーボード操作**: マウス操作は一切不要。すべての選択や決定がキーボードだけで簡単に行えます。
- **本格的な野球シミュレーション**:
  - 多彩な変化球（ストレート、カーブ、フォーク、シュート等）と、それぞれに強みを持つ個性豊かな投手陣！
  - 投球コース（高め・低め・内角・外角）と球種を見極め、タイミングを合わせてスイングします。
  - バッター側も個性派揃い。自分のプレイスタイルに合ったキャラクターを選んで打撃戦に挑めます。

## ⚠️ Windowsでの起動時に警告が表示される場合（SmartScreenの解除方法）

本アプリは個人が開発した未署名の実行ファイル（`.exe`）であるため、Windowsで初めて起動する際に **「WindowsによってPCが保護されました」** という警告画面（Microsoft Defender SmartScreen）が表示される場合があります。

これはセキュリティ上の一般的な動作であり、アプリの不具合やウイルスではありません。以下のキーボード・スクリーンリーダー操作で安全に実行できます。

### 【解除および起動の手順】
1. ダウンロードした `universal-baseball.exe` を起動します。
2. 警告画面が開いたら、**Tabキー** を数回押して **「詳細情報」** というテキストリンクを探します。
3. 「詳細情報」を選択して **Enterキー**（またはスペースキー）を押します。
4. 画面内にアプリ情報が表示され、新たにボタンが追加されます。
5. 再び **Tabキー** を押して **「実行」** ボタンを探し、**Enterキー** を押します。
6. これでゲームサーバーが起動し、自動的にブラウザが開きます。

※ 一度実行を許可すると、2回目以降は警告なしでそのまま起動できるようになります。

## 🎮 遊び方

1. ゲームを実行すると、自動的にブラウザ（`http://localhost:8080`）が立ち上がります。
2. 画面が開いたら、スクリーンリーダーの読み上げ、または画面内のテキスト表示に従って、キーボードで操作を行います。
3. **ゲームの流れ**:
   - 投手が投球を「準備」します。球種やコースの傾向のヒントを音声で確認します。
   - 投手がボールを「投球」します。
   - プレイヤーは、球種やコースを予測して **「振る（スイング）」** か **「見送る（テイク）」** かを選択します。
   - タイミングやコースの予測が合えばヒットやホームランになり、外れればストライクやアウトになります。

## 🛠️ 開発者向け：ビルド方法

本アプリはGo言語で開発されており、フロントエンドのコードをバイナリ内に埋め込むため、ビルドすると単一の実行ファイル（`.exe` など）が生成されます。

### 前提条件
- **Go 1.16 以上** がインストールされていること。

### ビルド手順

1. このリポジトリをクローンまたはダウンロードします。
2. リポジトリのルートディレクトリで以下のコマンドを実行します。

   ```bash
   # Windows向けに実行ファイルをビルドする場合
   go build -o universal-baseball.exe

   # macOS / Linux 向けにビルドする場合
   go build -o universal-baseball
   ```

3. 生成された実行ファイルを実行するだけで、自動的にサーバーが起動し、ブラウザでゲームが開始します。

### 開発時の実行（ビルドなしで実行）
コードを変更しながらテストする場合は、ビルドせずに直接実行できます。

```bash
go run .
```
